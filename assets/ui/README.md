# HUD artwork

`menu_reference.png` is an unchanged copy of the first image supplied by the user on 2026-10-05, with explicit permission to reuse it in this project. The HUD displays the stone menu using an AtlasTexture region `(91, 106, 990, 540)` and overlays six interactive buttons; the reference's two empty slots remain empty. No external game files were downloaded.

The remaining frames, bronze ornament, bars, compass, and marker are drawn by Godot. The character portrait renders the selected existing character model once in an isolated 192×192 viewport, updating when that model changes. The minimap uses the world's existing top-down render.
